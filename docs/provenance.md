# Data provenance and lawful use

| Question | Answer |
|---|---|
| External data used? | **None.** Every row is generated by `backend/pipeline` |
| Source URLs, datasets, versions | Not applicable |
| Retrieval date | Not applicable |
| Licence / terms | Not applicable. The generated data may be shared with this repository |
| Personal or confidential data | None. Names are random pairs from 40 first names and 30 last names in `pipeline/vocab.py` |
| Where do skill and course names come from? | Ten topic words per category, each combined with five aspects (`pipeline/vocab.py`), all written for this project |
| Transformations of external data | None |
| Fields discarded | None |
| Schema inspiration | General HR and learning-management concepts (roles, skills, courses, enrollments, budgets). No specific product or dataset was copied |

The generator is deterministic. The same seed (`20261022`) and scale give
byte-identical files, which `scripts/check_reproducibility.py` verifies and
records in `output/reproducibility/`.
